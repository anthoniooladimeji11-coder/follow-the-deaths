# Follow the Deaths

Interactive **Global Misalignment Index** for AMR research funding: how far each pathogen's share of R&D funding is from its share of deaths, and what it takes to close the gap.

- Preloaded with the six pathogens from our 2026 Vivli AMR Data Challenge study (Global AMR R&D Hub funding, GRAM 2019 burden, Bayesian 2030 projection).
- Works for any portfolio: edit the table or paste `name, funding, burden, late-stage projects`.

Single static page (`index.html`), no build step. Analysis code: [amr-funding-gap](https://github.com/anthoniooladimeji11-coder/amr-funding-gap).
