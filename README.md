# Follow the Deaths

Interactive **Global Misalignment Index** for AMR research funding: how far each pathogen's share of R&D funding is from its share of deaths, and what it takes to close the gap.

- Works for any portfolio and any pathogens: edit the table, paste, or upload a CSV (`name, funding, burden, late-stage projects, resistant %`).
- Tags each pathogen with its WHO Bacterial Priority Pathogens List 2024 tier and resistance type, and flags neglect (under-funded plus a thin pipeline).
- Ships with one dataset: six leading pathogens (Global AMR R&D Hub funding, GRAM 2019 burden, Vivli AMR Register resistance trends, Bayesian 2030 projection).

Single static page (`index.html`), no build step. Analysis code: [amr-funding-gap](https://github.com/anthoniooladimeji11-coder/amr-funding-gap).
